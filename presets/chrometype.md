# CHROME TYPE タイピング用の文字列

> 1 行 = 1 つの文字列。Typing を On にすると、拍に合わせて 1 字ずつ打ち込みます。
> 行頭の「- 」「* 」「1. 」は外して読みます。# で始まる見出し、> で始まる行、空行は読みません。
> 文字列の途中で改行するときは \n と書きます (例: SIGNAL\nLOST)。
> 書き換えて保存したら、CHROME TYPE パネルの Typing → Reload で読み直します。
> 記号や外国の文字は、選んだ書体に無くても Unifont VJ などの代わりの書体で描かれます (豆腐にならない)。
