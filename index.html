Q & A

          

            
何も映らない・真っ黒になった

            
Esc を押すと全スロットが透明 (なし) に戻ります。Visual のサムネをクリックして読み込み直してください。下段の A/B タイルが暗いときは表示 OFF なので、[ / ] かタイルのダブルクリックで戻します。Slot B は Mix の Opacity が 0 だと見えません。

            
どのスロットを操作しているのか分からない

            
マゼンタの枠が付いている方です (上の Slot A / B ボタンと下段のタイル)。X か、ボタン・タイルのクリックで切り替えます。読み込みやパラメータ操作は、このスロットに対して行われます。

            
自分の画像や動画を使いたい

            
Visual タブへファイルをドラッグ&ドロップするか、Visual の Image 欄・Movie 欄の先頭にある「＋」タイルから読み込みます。アプリ版・ローカル起動では images/drop/ と movies/ に保存されて次回も残ります。ウェブ版ではリロードすると消えます。

            
音に反応させたい

            
Timing の Audio Input で Mic か System を選びます。System は、ピッカーで「Chrome タブ」を選び「タブの音声を共有」にチェックしてください。反応の強さは Audio Detect で調整します。

            
テンポを曲に合わせたい

            
拍に合わせて T を数回叩きます (Timing の Tap と同じ)。BPM の大きな数字をクリックすると直接入力でき、Reset Φ で拍の頭を合わせられます。

            
値を元に戻したい

            
スライダーはダブルクリックでデフォルト値に戻ります。各欄の Reset はその欄を保存したデフォルトへ、R は FX / Params / Transition などをまとめて戻します (スロットは残ります)。直前の操作は Cmd/Ctrl + Z で取り消せます。

            
今の状態を残したい

            
Preset タブの「+ Save Current」で、全体の状態をプリセットにします。各欄の Save は、その欄の起動時のデフォルトを保存します。Settings の Restore を ON にすると、次回の起動で前回の状態に戻ります。

            
MIDI コントローラで動かしたい

            
スライダーかチェックボックスを右クリックしてから、つまみやボタンを動かすと割り当てられます。もう一度右クリックで解除します。Shader Params は各行右の MIDI ボタンでも割り当てられます。

            
外部ディスプレイに出したい

            
トップバーの Projector で出力専用のウィンドウを開き、外部ディスプレイへ移します。出力の解像度は Settings の Resolution で変えます。

            
重い・カクつく

            
P で Grad / Blend のプレビューバーを隠す、Settings の Output (FPS Cap・Resolution) を下げる、FX を減らす、の順で試してください。

            
録画したい

            
Record (Cmd/Ctrl + R) で開始・停止します。画面音声を ON にしていれば音声も入ります。静止画は Shot (Cmd/Ctrl + S) で PNG 保存です。
